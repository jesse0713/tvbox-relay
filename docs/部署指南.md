# 部署指南

从一台空电脑到电视能正常播放，大约 15 分钟。全程不需要 root / 管理员权限，只有放行防火墙那一步需要点一次 UAC。

## 0. 前置条件

| 项目 | 要求 |
| --- | --- |
| 中转机 | Windows 10 / 11（NAS、Linux 见第 9 节），需与电视同一局域网 |
| Python | 3.8 或更高，安装时勾选 **Add python.exe to PATH** |
| 电视 | 已安装 TVBox（或 FongMi 等兼容客户端），与中转机同网段 |
| 磁盘 | 点播缓存默认上限 4 GB，建议留 10 GB 空闲 |

验证 Python：

```powershell
python --version
# Python 3.12.x
```

若提示「不是内部或外部命令」，说明没加 PATH：重装时勾选，或把 `C:\Users\<你>\AppData\Local\Programs\Python\Python3xx\` 手动加进 PATH。

## 1. 获取代码

```bash
git clone https://github.com/jesse0713/tvbox-relay.git
cd tvbox-relay
```

没有 git 就下载 ZIP 解压。**目录结构不要改**：程序按 `relay/` 的上一级找 `sources.json`。

## 2. 首次启动

双击 `relay\启动中转.cmd`。它会：

1. 找 `pythonw.exe`（找不到就用 `python.exe`）；
2. 杀掉占用 8080 的旧进程（重复双击不会起两个）；
3. 后台启动 `tvbox-relay.py`；
4. 3 秒后打印 `[OK] relay is running: http://127.0.0.1:8080/`。

想在前台看日志，改用命令行：

```bash
python relay/tvbox-relay.py
```

浏览器打开 <http://127.0.0.1:8080/>，看到「TVBox 本机中转运行中」即成功。页面上的「服务地址」就是下面要填给电视的地址。

> 状态页里「最近体检」显示「尚未运行检测」是正常的，跑一次 `tools/daily-check.ps1` 或等计划任务就会更新。

## 3. 查本机局域网 IP

```powershell
ipconfig
```

找正在用的那块网卡（一般是「无线局域网适配器 WLAN」或「以太网」）的 **IPv4 地址**，形如 `192.168.1.23`。

> 建议在路由器里给这台机器做 **DHCP 静态绑定**（按 MAC 保留 IP）。否则路由器重启后 IP 可能变，电视上的地址就失效了。这一步在路由器后台「DHCP 保留 / 地址租约」里操作，不需要改本机设置。

## 4. 电视端配置

打开 TVBox：

| 位置 | 填 |
| --- | --- |
| 首页 → 设置 → 配置地址 | `http://192.168.1.23:8080/tv.json` |
| 首页 → 设置 → 直播源 / 添加直播 | `http://192.168.1.23:8080/live.m3u` |

填完点确定，回首页等几秒。第一次会慢（中转要去上游拉配置再改写），之后走本地缓存。

FongMi 影视等兼容客户端同理，只填 `/tv.json`，直播列表会被 `/tv.json` 自动注入，不必手动再加。

## 5. 放行防火墙（按需）

Windows 首次运行 Python 时通常会弹窗询问网络访问，选「允许」即可，此步可跳过。

如果电视打不开地址，但电脑本机浏览器能开：

```powershell
# 双击 relay\放行防火墙.cmd，UAC 点「是」
# 等价命令：
netsh advfirewall firewall add rule name="TVBox Relay 8080" dir=in action=allow protocol=TCP localport=8080
```

检查是否真的通了：

```powershell
# 在电脑上
netstat -ano | findstr :8080      # 应有 LISTENING
# 用手机连同一 WiFi，浏览器打开
http://192.168.1.23:8080/health   # 应显示 ok
```

## 6. 开机自启

**方式 A：启动文件夹（简单）**

`Win+R` → `shell:startup` → 把 `relay\启动中转.cmd` 的快捷方式拖进去。登录后自动后台拉起。

**方式 B：计划任务（登录后自动拉起，不弹窗口）**

```powershell
schtasks /Create /SC ONLOGON /TN "TVBox-Relay" /RL LIMITED ^
  /TR "\"C:\path\to\tvbox-relay\relay\启动中转.cmd\""
```

计划任务会短暂闪一下黑框，随后中转在后台运行。若希望电脑无人登录也能跑，建议把程序放到 NAS / Linux（第 9 节）。

## 7. 每日体检

```powershell
schtasks /Create /SC DAILY /ST 07:50 /TN "TVBox-Source-DailyCheck" ^
  /TR "powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\path\to\tvbox-relay\tools\daily-check.ps1"
```

它会拉每条视频源配置、抽测 10 个采集接口、抽测 16 个直播分片、跑点播站排序、确认中转在跑（不在就跑 `启动中转.cmd` 拉起），最后写：

- `report.txt` — 给人看的中文结论；
- `status.json` — 给程序/手机看的结构化结果，中转的 `/status.json` 直接暴露它。

退出码：`0` 全部正常，`1` 有源不可用（计划任务里能看到「上次运行结果」）。

## 8. 日常维护

| 场景 | 操作 |
| --- | --- |
| 换源 | 改 `sources.json` 的 `active`（或等体检自动改），**不用重启、不用动电视** |
| 加源 | 在 `video.items` / `live.items` 里加一项，`id` 唯一即可 |
| 看中转是否在跑 | <http://127.0.0.1:8080/health> |
| 看最近请求和切换 | `relay\relay.log`（超 2 MB 自动轮转为 `relay.log.1`） |
| 重启中转 | 双击 `relay\启动中转.cmd` |
| 清点播缓存 | 停服务后删 `relay\vodcache\s\` 下文件，或调小 `TVBOX_VOD_CACHE_MB` |

## 9. 部署到 NAS / Linux

程序只用标准库，任何有 Python 3.8+ 的环境都能跑。

```bash
# 1. 放代码
sudo mkdir -p /opt/tvbox-relay && sudo chown $USER /opt/tvbox-relay
git clone https://github.com/jesse0713/tvbox-relay.git /opt/tvbox-relay

# 2. 试跑
cd /opt/tvbox-relay && python3 relay/tvbox-relay.py

# 3. 装成服务
sudo tee /etc/systemd/system/tvbox-relay.service >/dev/null <<'EOF'
[Unit]
Description=TVBox relay
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
WorkingDirectory=/opt/tvbox-relay
ExecStart=/usr/bin/python3 /opt/tvbox-relay/relay/tvbox-relay.py
Restart=always
RestartSec=3
Environment=TVBOX_RELAY_PORT=8080
Environment=TVBOX_VOD_CONNS=28

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now tvbox-relay
systemctl status tvbox-relay
```

放行端口（按发行版选一条）：

```bash
sudo ufw allow 8080/tcp
# 或
sudo firewall-cmd --permanent --add-port=8080/tcp && sudo firewall-cmd --reload
```

NAS 上同理：群晖可用「计划任务 → 用户定义的脚本」在开机时执行 `python3 /volume1/tvbox-relay/relay/tvbox-relay.py`；Docker 环境自行用 `python:3-slim` 镜像挂载目录即可，无额外依赖。

## 10. 卸载

1. 删计划任务：`schtasks /Delete /TN "TVBox-Source-DailyCheck" /F`
2. 删启动项：`shell:startup` 里移除快捷方式
3. 结束进程：任务管理器结束 `pythonw.exe`，或 `Stop-Process -Name pythonw`
4. 删目录即可（缓存都在 `relay\vodcache`、`relay\cache` 里）

## 11. 上线检查清单

- [ ] `python --version` 正常
- [ ] `http://127.0.0.1:8080/health` 返回 `ok`
- [ ] 状态页能看到「服务地址」和当前 `active`
- [ ] 电视浏览器能打开 `http://<本机IP>:8080/health`
- [ ] TVBox 配置地址填的是 `/tv.json`
- [ ] 直播源填的是 `/live.m3u`
- [ ] 路由器已给中转机做 IP 保留
- [ ] 计划任务已建，手动跑一次退出码为 0
- [ ] 电脑不会自动睡眠（电源选项 → 睡眠 → 从不），或用 NAS 常开
